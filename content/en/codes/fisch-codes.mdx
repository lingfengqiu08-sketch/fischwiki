## Why a Fisch Code May Not Work

An error does not always mean you entered the wrong text. Expiration, progression restrictions, previous redemption, and temporary server problems can all prevent a code from awarding items.

| Problem | Likely cause | Recommended fix |
|---|---|---|
| “Expired” or invalid message | The redemption period ended | Verify the expiration time and wait for a new release |
| Level requirement message | Your character is below the required level | Reach the specified level before the deadline |
| Nothing happens | Server delay or temporary interface issue | Wait briefly, then rejoin and try once more |
| Code not recognized | Typo, incorrect capitalization, or extra space | Paste a clean copy of the code |
| Already redeemed message | The account previously claimed it | Check your inventory and currency balance |
| Reward appears missing | It was placed in another inventory category | Inspect boats, companions, consumables, and totems separately |
| A website requests login details | Scam or phishing attempt | Close the page and use Roblox directly |

- Paste the code again without leading or trailing spaces.
- Confirm that your account meets the stated level requirement.

Community reports can be helpful for identifying widespread outages, but treat them as **player experience**, not official confirmation. One player’s successful or failed redemption does not establish availability for every server or account.
